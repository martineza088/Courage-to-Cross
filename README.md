# Courage to Cross

A lightweight, responsive informational website about bridge-related fears and possible sources of support. Built with plain HTML, CSS, JavaScript, and a replaceable SVG image placeholder—no build step or package installation required.

## Pages

- **Learn** — `index.html`; introductory information and treatment overview
- **Find Help** — `find-help.html`; provider-search suggestions and external resources
- **Connect** — `connect.html`; ideas for seeking understanding and support
- **Explore** — `explore.html`; common questions and further reading
- **About** — `about.html`; project purpose and content boundaries
- **Support This Site** — `support-this-site.html`; fundraising-page guidance and the requested GoFundMe placeholder link

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Customize

Replace `assets/bridge-vector.png` with your own image and update the image references and alternative text on each page. Review all health information, external links, and fundraising language before publishing. The support link currently opens GoFundMe's campaign creation page, not an active campaign.

This site is for general informational purposes only and is not a diagnosis or substitute for professional care.
